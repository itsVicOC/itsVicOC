## 关于我

我喜欢把一个模糊的想法，打磨到真正能运行、能交互、能交付。从终端里的掼蛋 AI，到浏览器中的塔防和每日谜题；从 GUI / CLI 双模式工具，到原生 macOS 和跨平台桌面应用。

- **游戏与互动**：把规则、策略和即时反馈，变成一段可以参与的体验。
- **工具与效率**：从真实使用场景出发，让重复操作更省心。
- **跨端探索**：Web、终端、桌面与小程序，选择适合问题的载体。

## 精选作品

### 游戏与互动

- **[guandan · 终端掼蛋](https://github.com/itsVicOC/guandan)**<br />
  本地 TUI 游戏，内置 5 档 AI，让复杂牌型与不同风格的对手在终端里相遇。<br />
  `Python` `TUI` `Game AI`

- **[PathForge TD · 迷宫塔防](https://github.com/itsVicOC/pathforge-td)**<br />
  在 Canvas 棋盘上规划路径、布置防线，把迷宫和塔防组合成可玩的策略实验。<br />
  `TypeScript` `Canvas` · **[在线体验 ↗](https://itsvicoc.github.io/pathforge-td/)**

### 桌面与效率

- **[bilibili-downloader · 桌面下载工具](https://github.com/itsVicOC/bilibili-downloader)**<br />
  同一套下载能力，提供 GUI 和 CLI 两种入口。<br />
  `Python` `Desktop` `GUI + CLI`

- **[MangaViewer · 本地漫画阅读器](https://github.com/itsVicOC/mangaViewer)**<br />
  管理本地漫画库与阅读进度，支持多种文件格式、双页和长条阅读。<br />
  `Tauri` `React` `TypeScript` `Rust`

### 资料与探索

- **[PolishedDex CN · 抛光水晶图鉴](https://github.com/itsVicOC/polishedDexCN)**<br />
  面向 Pokémon Polished Crystal 的中英双语资料库，串联图鉴、攻略与实用查询工具。<br />
  `TypeScript` `PWA` · **[打开图鉴 ↗](https://itsvicoc.github.io/polishedDexCN/)**

- **[汉字启蒙 · 亲子识字](https://github.com/itsVicOC/hanzi-study)**<br />
  用象形识字与字卡游戏，让家长陪孩子每天花一点时间，轻松认识汉字。<br />
  `TypeScript` `Web` · **[在线体验 ↗](https://itsvicoc.github.io/hanzi-study/)**
